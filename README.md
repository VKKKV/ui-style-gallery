# Kita UI Gallery

5 hand-curated UI style demonstrations, each with full HTML/CSS implementations:

| # | Style | Theme | Best For |
|---|-------|-------|----------|
| 1 | **Tactical HUD** | #000 + #0f0, scanlines, telemetry | Dashboards, CLI tools, DevOps |
| 2 | **Dark Swiss** | #000 + Inter, typography-only | Documentation, enterprise |
| 3 | **Neubrutalism** | #fff + 3px borders, raw honesty | Personal brands, landing pages |
| 4 | **Apple / Spatial** | #f5f5f7 + pill buttons, precision | Product pages, SaaS |
| 5 | **Nous / Hermes** | #0000f2 + serif hero, blend art | Brand sites, poster landing |

Inspired by Hermes Agent, Apple Vision Pro, Brutalist web design, and classic Swiss typography.

## Usage

Open `index.html` in a browser. Navigate between styles using the sticky top bar.

Art assets sourced from [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/).
