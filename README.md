# UI Style Gallery

5 hand-curated UI style demonstrations, each with full HTML/CSS implementations:

| # | Style | Theme | Best For |
|---|-------|-------|----------|
| 1 | **Tactical HUD** | #000 + #0f0, scanlines, telemetry | Dashboards, CLI tools, DevOps |
| 2 | **Dark Swiss** | #000 + Inter, typography-only hierarchy | Documentation, enterprise apps |
| 3 | **Neubrutalism** | #fff + 3px borders, offset shadows, honest design | Personal brands, landing pages |
| 4 | **Apple / Spatial** | #f5f5f7 + pill buttons, large-radius cards | Product pages, SaaS |
| 5 | **Nous / Hermes** | #0000f2 + lighten-blend art, serif hero | Brand sites, poster landing pages |

Inspired by Hermes Agent, Apple Vision Pro, Brutalist design, and Swiss typography.

## Use

Open `index.html` in a browser. Navigate between style sections via the sticky nav bar.

## Structure

```
index.html         — single-file gallery with all CSS inline
assets/            — hero art and feature images
```

Art assets sourced from [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/).
