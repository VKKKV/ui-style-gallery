Choose Canvas 2D when…

  • the page is static and dependency-free
  • the particle count stays moderate
  • mobile fallback matters more than shader polish

Choose Three.js / shader when…

  • glow, noise, depth and fluid motion matter
  • you want a GPU-ready path for later scaling
  • you can ship a WebGL fallback and test real devices

IMPLEMENTATION NOTE — vanilla Canvas 2D powers the main stage, sampled text, cached glyph atlas and orbital study. GPU Point Field uses native WebGL with a Canvas 2D fallback. No rendering library is loaded; fonts fall back to system faces. Pause stops all demos, and reduced-motion preferences start with static targets.
